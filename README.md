# Jed Miclsen R. Cada | Portfolio (React + TypeScript + Vite)

    npm install
    npm run dev        # local dev server
    npm run typecheck  # TypeScript check
    npm run build      # production build in dist/

- `src/App.tsx`: scene state (room / Headspace / Whitespace), fade transitions
- `src/components.tsx`: UI components (Resume modal, tabs, cards, sliders)
- `src/engine.ts`: pixel-art canvas scenes and animations (typed `initEngine`)
- `src/styles.css`: styling
- Replace the placeholder projects, videos, photos, graphics, resume and contact text in `src/components.tsx`.
